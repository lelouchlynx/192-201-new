CampusWheels

CampusWheels is a small vehicle-rental program made for Assignment 2.
It uses classes to represent vehicles, renters, electric cars, and motorbikes.

The program demonstrates:

renting and returning a vehicle

checking invalid renter details

inheritance with ElectricCar and Motorbike

polymorphism by printing different vehicle types from one list

How to run

Open the Assignment_02 folder and run:

python main.py

Files

rental.py — contains the Vehicle, Renter, ElectricCar, and Motorbike classes

main.py — demonstrates the required features

README.md — project information and run instructions
